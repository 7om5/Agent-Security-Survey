# 单篇笔记质量检查清单（每批使用）

## A. 阅读覆盖
- [ ] 正文从 Introduction 到 Conclusion 逐节读，不是只读摘要/引言/结论。
- [ ] Threat Model 已找到；若原文无独立小节，注明定义位置。
- [ ] Method/Design 的公式、伪代码、架构图已核对。
- [ ] Evaluation 的模型、数据、基线、指标、主结果、消融均有记录。
- [ ] Discussion/Limitations 已读。
- [ ] 与方法/攻击/实验/证明相关的附录已读；参考文献页注明“仅浏览”。
- [ ] 关键图/表至少 1–3 个用 PNG 渲染核对（若文本可完整表达，注明理由）。

## B. 笔记结构
- [ ] 14 节齐全。
- [ ] 头部有 `深读覆盖：X / N 页`。
- [ ] 至少 8–10 条证据，含 PDF 页码 + 章节/图/表/公式。
- [ ] 关键数字附实验条件，不跨设置直接比较。
- [ ] 第 10/11 节区分“论文已做”与“本人推断”。
- [ ] 第 14 节勾选完备性。

## C. 密码学判断纪律
- [ ] 不因出现 OAuth/签名/ZK/privacy 等词自动给密码学高分。
- [ ] 明确区分：密码学构造/证明 vs 系统访问控制/LLM 策略/工程集成。
- [ ] 伪交叉风险有记录（仅签名日志、仅包装 OAuth、仅证明单步执行等）。
- [ ] 未把“本文没提”推断为“领域没人做”。

## D. 机器检查
```bash
node scripts/check_note.js <ID...>
node scripts/audit_coverage.js
```
