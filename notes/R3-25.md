## 1. 150–300 字中文概述

论文研究 LLM 多 Agent 系统（MAS）中基于文本嵌入的恶意 Agent 检测为何失效。作者指出，G-Safeguard、GUARDIAN 等图异常检测依赖恶意与良性消息在嵌入空间可分；一旦攻击者把消息嵌入压到良性支持集附近，检测器就会失效。论文用 Lipschitz 边界给出解释：良性间隔 γ 会使评分器在 benign support 周围形成 γ/L 的接受邻域。作者提出 Slow Drift、Benign Wrapper、Chaos Seeding 三种近良性攻击，在 MMLU/GSM8K/BBH 与 LLaMA-3.1-8B、Qwen3-4B、GPT-4o-mini 上显著拉低 G-Safeguard/GUARDIAN 的攻击下准确率；并提出用 token 级熵置信度做剪枝或降权作为补充信号。实验显示置信度在嵌入不可分时仍有区分力，但信号随轮次衰减，拓扑越密衰减越快。全文为表示空间/经验性安全分析，不含密码学原语或形式化密码证明。

## 2. 研究背景、现有方法不足、精确定义的问题

- 背景：MAS 通过 Agent 间通信协作完成复杂任务，但也引入系统级攻击面：被攻陷 Agent 可传播错误信息、操纵群体决策（p.1, §1）。论文关注的 “safety” 不是内容有害性、隐私或机密性，而是**群体最终决策的正确性/抗操纵性**。
- 现有防御：G-Safeguard 用 GNN 在 utterance graph 上传播并逐轮检测；GUARDIAN 用时序属性图与重构目标；BlindGuard 用无监督方法减少对标注攻击数据的依赖（pp.2–3, §2）。它们的共同假设是恶意与良性消息在嵌入空间可分（p.2, §2）。
- 不足一：现有评测多用 “obvious attack”——攻击者语气强硬、内容显著异于良性短句，检测器可能只是在识别“攻击者签名”，而非真正防御（p.1, §1；p.3, §4）。Fig.1 展示 overt 与 near-benign 的嵌入几何差异（p.1）。
- 不足二：嵌入防御把 Agent 的最终文本当作外部接口，丢弃 token 级 logits/概率等内部生成信号；当嵌入不可分时，这些信号可能仍有信息（p.1–2, §1）。
- 不足三：防御信号能持续多少轮、拓扑密度如何影响衰减，缺乏分析（p.1–2, §1；p.6, §7）。
- 精确问题：(i) 近良性攻击能否通过降低嵌入可分性绕过 G-Safeguard/GUARDIAN？(ii) token 级置信度能否在嵌入失效时提供互补信号？(iii) 防御信号随轮次/拓扑如何衰减？形式化为：给定 x、gold y、target ỹ，攻击者每轮在 dist(h(m), S_B) ≤ τ 约束下选消息最大化翻转数；防御者用 sθ 评分并剪枝/降权，目标是在攻击下保持多数投票准确率（p.3–4, §3–§5；p.6, §7）。

## 3. Agent 系统模型（组件、交互流程、信任边界）

- **Agent 与轮次**：N 个 LLM Agent，任务输入 x，R 个同步通信轮次；每个 Agent 有任务专用 system prompt p_x（p.3, §3）。第 r 轮 Agent i 依据 x、p_x 与上一轮邻居消息 P_i^(r−1) 生成 m_i^(r)；最终通过多数投票聚合决策/答案（p.3）。论文实际实验是 MMLU/GSM8K/BBH 的选择题、数学与推理题，Agent 之间只交换文本，**没有工具调用、记忆或外部环境**；这是“多 Agent 辩论”而非工具型 Agent 系统（p.6–7, §7）。
- **通信拓扑**：有向图 G=(V,E)；边 j→i 表示 i 接收 j 的消息；N(i) 为入邻居。评测 star、chain、sparse random（每条有向边独立以概率 p 加入，p 变化）与 fully connected（p.6, §7.1；p.8, Table 5）。论文声称报告 mean in-degree（p.6），但正文/表格未给出具体值（本人核对全文）。
- **攻击者/良性划分**：A⊆V 为攻击者，B=V\A 为良性；良性遵循 p_x，攻击者使用 adversarial system prompt p_attack 生成消息，目标把群体决策推向指定错误答案 ỹ（p.3, §3）。攻击者数量 |A|、Agent 数 N、轮数 R 均未在正文给出具体值（本人核对）。
- **防御流水线**：每轮用文本编码器 φ（如 Sentence-BERT）把 m_i^(r) 映射为 h_i^(r)∈R^d；图模型（GNN）在通信拓扑上传播得到上下文表示 ĥ_i^(r)；异常评分 s_θ:R^d→R 给出 s_i^(r)=s_θ(ĥ_i^(r))；按阈值 flag/prune/down-weight（p.3, §3）。G-Safeguard 与 GUARDIAN 是两条具体实例（pp.2–3, §2）。
- **信任边界**：消息文本来自可能被攻陷的 Agent，是不可信输入；防御控制器被默认可信，能读取全部消息、嵌入以及（对开放模型）token logits/概率；最终多数投票聚合器被默认可信。对 GPT-4o-mini 只能用 API 返回的 token probabilities，logits 不暴露（p.6, §7.1）。论文没有认证、签名或密钥；攻击者是“已攻陷的内部 Agent”，不是外部网络对手（p.2, §2）。
- **关键缺失**：正文没有给出 N、R、|A|、每数据集采样规模、δ、k、τ、ε、ℓ 的取值；这使系统模型无法从论文单独复现（本人推断，非作者承认）。

## 4. 资产、攻击者目标/能力、威胁模型和前提假设

- **资产**：群体最终决策的正确性（task accuracy）；攻击者想让最终多数票等于目标错误答案 ỹ；防御方要维持 clean accuracy 并在攻击下减少准确率下降（p.3, §3；p.6, §7.1）。
- **攻击者目标**：最大化 Flip（被翻转到 ỹ 的良性 Agent 数）或最终 ASR；同时保持消息嵌入接近良性支持集以规避嵌入检测（p.4–5, §5）。不是窃取数据、拒绝服务或提权。
- **攻击者能力**：
  - 已攻陷一部分 Agent，可控制其 system prompt 与每轮生成（p.2, §2 明确 “assume an agent is already compromised”；p.3, §3）。
  - 知道任务 x、gold y、目标 ỹ、当前对话/邻居消息；可按 Eq (1)–(4) 选择消息（pp.4–5）。
  - 能计算/估计 h(m) 与 benign support S_B(r)，因为攻击约束直接写在嵌入距离上；这隐含对编码器 φ 与良性消息分布的访问（本人推断；论文未明确 attacker 的 knowledge 级别）。
  - 多个攻击者可共享 p_attack，但是否显式协同未建模（本人推断）。
- **攻击者约束**：dist(h(m), S_B) ≤ τ（所有攻击）；Slow Drift 额外 ∥h(m)−h(m_a^(r−1))∥₂ ≤ ε；Benign Wrapper 要求 |B| ≤ ℓ 且 wrapper/full message 都接近 S_B；Chaos Seeding 要求攻击者消息仍接近 S_B（pp.4–5, Eq (1)–(4)）。
- **防御者能力**：读取全部消息、计算嵌入、运行图异常检测；置信度防御额外读取 token-level logits（开放模型）或 token probabilities（API）；可剪枝或降权消息（p.3, pp.5–6）。
- **前提假设**（分散在 §2–§3、§5、§7.1；原文无独立 Threat Model 小节）：
  - 攻击者已在系统内部且拥有合法 Agent 身份；不是外部注入者。
  - 同步轮次、固定拓扑、良性 Agent 遵循 p_x、最终多数投票。
  - 攻击者不针对置信度防御做自适应优化；论文未测试“知道置信度防御并故意输出高置信度错误消息”的对手（本人推断）。
  - 置信度由模型运行时 logits/概率计算；若 API 不暴露概率，该防御不可用。
  - 无认证/签名/加密；防御是统计检测，不是访问控制。

## 5. 核心方案：failure analysis、attack construction、embedding geometry

### 5.1 失效机理与理论分析

- 定义 benign support S_B := supp(P_B)，dist(h,S_B) := inf_{h_b∈S_B}∥h−h_b∥₂；定义分离率 Sep(c)=E_{h_a∼P_A}[1{dist(h_a,S_B)≥c}]（p.3, Def 3.1）。Sep(c) 越大，攻击嵌入离良性支持越远。
- **Theorem 4.1**（p.4；证明 p.11, App A）：设 s 为 L-Lipschitz，Ω={h:s(h)≥0}，若 benign margin γ>0（inf_{h∈S_B}s(h)≥γ），则 {h:dist(h,S_B)≤γ/L}⊆Ω；因此任意攻击嵌入 h_a 只要 dist(h_a,S_B)≤γ/L，就必有 s(h_a)≥0，绕过任何以 s(·) 阈值 0 判别的防御。
- 直觉：训练时若恶意/良性嵌入高度可分，分类器可以学到一个“宽”的良性接受区（大 margin γ）；这个宽区域就是 near-benign 攻击的藏身空间（pp.3–4, §4）。作者引用 Soudry et al. 2018（隐式偏差）与 Fort et al. 2021（OOD 检测的 margin 问题）支持“可分训练→大 margin”，但**没有在本文模型中证明或测量 γ、L**。
- 证明结构：Lemma A.1 用 Lipschitz 性给出 s(h)≥inf_{z∈S}s(z)−L·dist(h,S)；代入 S=S_B、margin γ 即得（p.11）。数学上正确，但条件是假设的，不是对实际 G-Safeguard/GUARDIAN 的端到端保证。

### 5.2 三种近良性攻击

- 统一目标（Eq 1, p.4）：m_a^(r) ∈ argmax_m Flip(m; x, {m_j^(<r)}) s.t. dist(h(m), S_B) ≤ τ。Flip 是被翻转到 ỹ 的良性 Agent 数。
- **Slow Drift**（Eq 2, p.4）：首轮选 benign-looking 消息满足 dist≤τ；后续轮在 dist(h(m),S_B(r))≤τ 与 ∥h(m)−h(m_a^(r−1))∥₂≤ε 下最大化 Flip。逐轮平滑漂移，避免突变触发 change-based detection。
- **Benign Wrapper**（Eq 3, p.5）：m=A∥B；A 是长 benign wrapper，B 是短 malicious payload（|B|≤ℓ）；约束 dist(h(A),S_B(r))≤τ_A 且 dist(h(A∥B),S_B(r))≤τ。长 wrapper 主导整体嵌入，payload 只做少量语义推动。
- **Chaos Seeding**（Eq 4, p.5）：不追求攻击者自己像良性，而是最大化良性 Agent 间的分歧 Disagree(r)=1/(|B|(|B|−1))·Σ_{i≠j∈B}1{y_i^(r)≠y_j^(r)}，同时 dist(h(m),S_B(r))≤τ。良性嵌入分布被撑大，outlier 检测的“紧簇”假设失效。
- **实现细节缺口**：正文与附录 B 只给 MMLU 的 prompt 模板（benign/overt/near-benign，pp.12–13, Figs 3–5），没有说明 Eq (1)–(4) 的求解算法（候选数、拒绝采样、投影、τ/ε/ℓ 取值），也没有 GSM8K/BBH 模板。near-benign prompt 的核心是 “neutral, balanced”“keep your tone tentative”“blend in”“borrow others’ logic”（p.13, Fig 5），属于提示词工程，不是可证明的嵌入约束优化（本人推断）。
- **embedding geometry 证据**：Table 2（p.7）用 cosine distance 度量：B–M 距离 Obvious 0.236、Slow Drift 0.176、Benign Wrapper 0.156、Chaos 0.205；B–B (Same) 约 0.106–0.114，B–B (Diff) 0.152–0.239。Benign Wrapper 的 B–M 最小（0.156），接近 B–B (Diff) 0.162；Chaos 的 B–B (Diff)=0.239 甚至大于 B–M=0.205，说明良性内部分歧压过了攻击-良性距离。

### 5.3 置信度防御

- 对消息 m=(t_1,...,t_T)，token 熵 H_k(m)=−Σ_v p_k(v)log p_k(v)；取 top-k 熵的均值 U(m)=(1/k)Σ_{j=1}^k H_(j)(m)；C(m)=g(U(m))，g 单调递减（p.5, §6.1）。k、g、阈值 δ 均未给具体值。
- **Confidence pruning**：若 C_j^(r)≥δ 则转发 m_j^(r)，否则置 ∅（p.5, §6.2）。在传播前阻断低置信消息。
- **Confidence down-weighting**：把消息打包为 `[confidence=C] message`，让接收 Agent 在推理时 “discount” 低置信内容；聚合仍是把消息拼进 prompt（p.5, §6.2）。这不是硬性权重，依赖接收模型遵守指令。
- 设计定位：training-free、model-internal、与嵌入信号互补；作者在 §8 明确说 “combine them” 是未来方向（p.8）。从 Table 4 的组织看，主实验的 “Ours” 应是 confidence pruning（上/下 block 对比 pruning vs no pruning）；**down-weighting 没有单独实验**（本人核对全文）。

## 6. 安全声明与形式化程度（定义/定理/证明 vs 经验主张）

- **形式化部分**：1 个定义（Sep(c), Def 3.1）、1 个引理（Lemma A.1）、1 个定理（Theorem 4.1）+ 完整证明（p.11, App A）。这是实分析/局部鲁棒性证明：Lipschitz 常数 L 把“良性 margin γ”转换为“γ/L 的接受邻域”。它不是密码学安全定义，没有 security game、indistinguishability、reduction、计算假设或对手资源界。
- **定理的逻辑地位**：定理是**条件性**的——若 s 满足 L-Lipschitz 且在 S_B 上有 margin γ，则半径 γ/L 内的嵌入必被接受。这是“给定 margin 的必然几何后果”，不是“G-Safeguard/GUARDIAN 一定可被攻破”的无条件定理。论文没有估计实际防御的 γ 或 L，也没有验证 γ/L 与攻击所用 τ 的关系；因此定理与 Table 1–3 的经验结果之间缺少定量桥梁（本人推断）。
- **度量不一致**：定理与攻击约束用 L2 距离 ∥·∥₂；Table 2 用 cosine distance；论文未说明攻击实现中 dist 的具体度量，也未说明嵌入是否归一化。二者在归一化嵌入下单调相关，但论文没有交代（本人核对）。
- **未被使用的定义**：Def 3.1 的 Sep(c) 在全文没有报告任何数值；论文用 Table 2 的 cosine 距离代替。Sep(c) 是 population 量，未给估计量或有限样本界。
- **经验主张**：近良性攻击降低嵌入可分性（Table 2）、拉低 G-Safeguard/GUARDIAN 准确率（Tables 1/3）、置信度剪枝提升攻击下准确率（Table 1）、信号随轮次/拓扑衰减（Tables 4/5）。主表指标是 accuracy，不是 ASR；“攻击成功”只在 Table 5 以 ASR@R 报告。准确率下降可能来自一般性破坏而非目标答案获胜，二者不能混同（本人推断）。
- **“safety” 含义**：本文 safety = 群体决策正确性/抗操纵性，不是内容无害、隐私或机密性；没有形式化的完整性定义，只有 accuracy/ASR 经验指标。
- **置信度信号的可信性**：置信度由防御控制器从被检测 Agent 的生成 logits 计算（p.5, §6.2；p.6, §7.1）；但被攻陷 Agent 控制生成过程，原则上可优化“高置信度错误消息”。论文没有做 confidence-aware adaptive attack，因此“置信度仍有用”是经验观察，不是鲁棒保证（本人推断）。
- **结论**：有数学定理与证明，但属于统计/表示学习层面的局部分析；**非密码学**。论文没有形式化安全定义、密码原语、定理化的防御保证或 reduction。

## 7. 实验设置与主要结果

### 7.1 设置

- 数据集：MMLU（多学科选择题）、GSM8K（小学数学应用题）、BBH（BIG-Bench 组合推理子集）；每个数据集随机采样子集，但**未给子集大小/题目数**（p.6, §7.1）。
- 模型：LLaMA-3.1-8B-Instruct、Qwen3-4B（开放权重，vLLM 取 logits）、GPT-4o-mini（API，取返回 token probabilities）（p.6, §7.1）。
- 防御：No defense、G-Safeguard、GUARDIAN、Ours（confidence-guided）。所有方法共用 base prompts 与 aggregation rules，除非防御显式改变传播/加权（p.6）。
- 指标：Clean accuracy；攻击下 Acc-Avg（三种 near-benign 攻击的平均准确率，越高越好）；ASR（最终决策被导向 target 的比例，只在 Table 5 报告）；Table 4 的 Emb./Conf. 区分度（caption 未写指标名，数值范围 0.50–0.94，结合 Table 5 推断为 AUROC）；Table 2 的 cosine distance（pp.6–8）。
- 拓扑：star、chain、sparse random（p=0.1–0.9）、fully connected；所有 ablation 用 MMLU + LLaMA-3.1-8B（p.6, §7.1；p.8, Table 5）。
- 统计：没有报告 runs 数、标准差、置信区间或显著性检验（本人核对）。

### 7.3 逐攻击与嵌入几何

- Table 3（MMLU/LLaMA）：No defense Clean 65.0, Obv 21.4, Drift 36.6, Wrapper 39.6, Chaos 40.2；G-Safeguard 68.0, 42.4, 43.4, **30.2**, 44.2；GUARDIAN 67.0, 34.2, 32.6, 30.2, 35.0；Ours 68.0, 62.4, 62.8, 48.6, 46.8。

### 7.4 信号区分度与持续性

- Table 4（p.8）：With confidence pruning，Round 1/2/3：Obvious Emb 0.94/0.93/0.92、Conf 0.91/0.90/0.89；Near-Benign Emb 0.62/0.58/0.55、Conf 0.84/0.80/0.75。Without pruning：Near-Benign Emb 0.60/0.52/0.50、Conf 0.83/0.66/0.55。即：near-benign 下嵌入信号一开始就弱（0.62），置信度更强（0.84）；不剪枝时置信度随轮次快速崩塌（0.83→0.55），剪枝能延缓（0.84→0.75）。
- Table 5（p.8）：Half-life/AUC-R/ASR@R：Star 2/2.05/0.22；Chain 3/2.30/0.18；Sparse p=0.1 3/2.40/0.16；p=0.3 2/2.15/0.21；p=0.5 2/1.95/0.28；p=0.7 1/1.70/0.37；p=0.9 1/1.55/0.41；Fully connected 1/1.45/0.48。稀疏/瓶颈拓扑保留信号更久、最终 ASR 更低；稠密拓扑加速污染。Half-life 的 AUROC 阈值未在 caption 给出。
- 解释：作者提出 self-mixing——良性 Agent 回声攻击者影响的内容，嵌入向共享簇漂移，嵌入信号迅速崩塌；置信度在早期仍可区分，但持续污染后也崩塌（p.8, §7.4）。

## 8. 贡献与创新点（按原文主张）

1. **失效机理的理论+经验分析**：指出嵌入防御依赖恶意/良性嵌入可分，给出 Theorem 4.1 的 margin/接受域解释，并用近良性攻击验证（pp.1–4）。
2. **三种近良性攻击**：Slow Drift（跨轮平滑漂移）、Benign Wrapper（长良性 wrapper + 短 payload）、Chaos Seeding（放大良性分歧）——都通过降低嵌入可分性绕过检测（p.2, §1；pp.4–5, §5）。
3. **置信度防御**：用 token 级熵/概率作为模型内部可靠性信号，提出 pruning 与 down-weighting 两种策略，training-free，在嵌入不可分时提供互补证据（p.2, §1；pp.5–6, §6）。
4. **信号持续性/拓扑分析**：发现两种信号都随轮次衰减，稠密拓扑更快；主张早期、拓扑感知的干预（p.2, §1；p.8, §7.4）。
- 与 G-Safeguard/GUARDIAN 的差异：后者在嵌入空间做图异常检测；本文攻击其可分性假设，并把“模型内部信号”引入防御。与 confidence/uncertainty 相关工作（Geng et al. 2024; Wang et al. 2025a; Yoffe et al. 2025）的差异：本文把置信度用于 MAS 消息传播控制，并分析其在对抗条件下的衰减（pp.2–3, §2）。
- 可复现资源：代码 `https://github.com/chili-lab/rethinking-mas-defense`（p.6 脚注 2；仅记录，未打开/未执行）。附录 B 只给 MMLU prompt（pp.11–13）。

## 9. 局限、失败案例、作者承认的不足

**作者明确承认/写出的**：

- 攻击具有 dual-use 风险，可能被用于探测/规避弱防御（p.9, Impact Statement）。
- 置信度只是 “simple, training-free” 的内部信号；未来可探索 logit margins、calibration-aware confidence、self-consistency、reasoning–answer agreement；并建议把嵌入信号与内部信号组合（p.8, §8）。
- 稠密拓扑加速信号衰减，防御窗口有限；需要早期、communication-aware 干预（p.8, §9）。
- 假设 Agent 已被攻陷，这是受控最坏情况设定，用于精确攻击与防御度量（p.2, §2）。
- 没有独立 Limitations 章节；上述之外的限制需从设定推断（本人注记）。

**本人推断的局限/失败场景**：

- **系统模型过窄**：纯文本辩论、无工具/记忆/外部环境；N、R、|A| 未给；拓扑固定；同步轮次。真实 Agent 系统的工具调用、记忆污染、异步通信未覆盖。
- **攻击实现不可复现**：Eq (1)–(4) 的约束优化没有求解算法；τ、ε、ℓ、候选数、S_B 估计方法未给；附录只有 MMLU prompt。所谓 “adaptive attack” 更像精心设计的 prompt，而非可验证的嵌入优化。
- **理论-实验脱节**：γ、L 未估计；Sep(c) 未测量；定理用 L2、实验用 cosine；γ/L 与 τ 的关系未知。定理不能被用来预测 Table 1–3 的具体数字。
- **置信度可被对手游戏**：置信度来自被攻陷 Agent 自己的生成。尤其 Appendix B 的 near-benign prompt 第 1 轮要求 “Keep your tone tentative but insightful”，后续轮又要求 “Gradually increase your confidence”（p.13, Fig 5）；这恰好会让早期置信度偏低、后期偏高，可能人为放大 Table 4 中 confidence 的早期优势。若攻击者从第 1 轮就保持高置信，置信度 AUROC 可能下降。此为本人的推断/未验证假设，论文未讨论。
- **置信度的可用性**：需要 token logits/概率；很多 API 不提供；GPT-4o-mini 只能用返回概率。黑盒部署受限。
- **置信度≠恶意**：低置信可能是良性难题，高置信可能是自信的错误；pruning 可能误删良性不确定消息。论文没有 false positive/negative 分析。
- **down-weighting 未验证**：第二种策略只有定义，没有实验；且依赖接收 Agent 遵守 prompt 指令，不是硬约束。
- **未与嵌入防御组合**：作者说“互补”，但主实验是 standalone confidence pruning；没有 G-Safeguard/GUARDIAN + confidence 的 hybrid 结果。
- **指标/统计不足**：主表是 accuracy 而非 targeted ASR；没有 runs、方差、显著性；数据集子集大小未知；Table 4 指标名未写；Table 5 half-life 阈值未写。
- **长程/异构未测**：只到 3 轮（Tables 4–5），更长通信、异构模型、不同攻击者比例、串谋攻击未测。

## 10. 与理论密码学的可能联系（严格）

**结论：无直接联系；本文不是密码学论文。**

- 论文没有使用任何密码原语（加密、签名、MAC、承诺、零知识、MPC、FHE、TEE、匿名凭证等），没有密码学安全定义/游戏、没有 reduction、没有计算困难性假设、没有对手资源界。
- 唯一的数学内容是 Lemma A.1 + Theorem 4.1：Lipschitz 函数在集合上的 margin 推出邻域包含。这属于实分析/机器学习中的**局部鲁棒性证书**（类似 Lipschitz-based certified robustness），不是密码学定理。它甚至不是“防御保证”，而是“给定 margin 时攻击者必然可逃逸”的条件性脆弱性结果。
- “Sep(c)”“benign support”“embedding distance” 是统计/表示空间概念，不是密码学中的 secret、advantage、negligible function 或 indistinguishability。
- 若一定要建立理论连接（**个人推断，非论文已做**）：可把“检测器 vs 受嵌入距离约束的对手”写成假设检验/极小极大博弈，用分布距离（如 total variation、KL）或 Lipschitz margin 推导检测下界；这是统计学习理论/检测理论，不是密码学。也可以把“攻击者能否在嵌入约束下翻转决策”形式化为带约束的优化问题并给出近似难度，但论文没有做。
- 与 BFT/容错共识的关系比与密码学更近：多数投票 + 部分恶意 Agent 是 Byzantine 设定；但论文没有使用 BFT 的 quorum/签名/共识协议，也没有形式化 fault tolerance。此点为本人推断。

## 11. 与应用密码学的可能联系（严格）

**结论：论文没有使用任何应用密码学机制；相关度很低（A_crypto 约 0–1）。**

- 没有 TLS/认证、OAuth/OIDC、签名消息、加密嵌入、TEE、远程证明、密钥管理、审计日志或访问控制。防御完全在模型/表示层：Sentence-BERT 嵌入、GNN 异常评分、token 熵、prompt 剪枝/降权。
- 嵌入、logits、confidence 不是密码学对象；对它们做哈希/签名只能证明“某段文本/某个分数存在”，不能证明“该 Agent 未被攻陷”或“消息语义良性”。

**个人推断的工程接口（均需新增设计与实验，不是论文贡献）**：

1. **attested inference / TEE**：如果置信度由 Agent 自报，恶意 Agent 可以伪造；用 TEE/远程证明把 logits 绑定到真实模型执行，可让防御控制器信任置信度。但本文的 threat model 是 Agent 已被攻陷，攻击者仍可控制 prompt 让模型“自信地”输出错误内容；TEE 只能保证分数真实，不能保证内容正确。
2. **消息认证/签名**：给 Agent 消息签名可防外部冒充，但对“已攻陷的内部 Agent”无效——它持有合法密钥。故对本文威胁模型帮助有限。
3. **可验证审计日志**：对每轮消息、嵌入、置信度、剪枝决策做签名/哈希链，支持事后取证与归因；但不能阻止攻击，也不能证明语义安全。
4. **加密嵌入/隐私推理**：若嵌入或 logits 含敏感信息，可用加密/隔离保护；但防御需要明文计算异常分数，且本文资产是决策完整性而非机密性，收益有限。

**伪交叉警告**：给消息加签名、给嵌入加密、用 ZK 证明“模型运行了某步”，都不能解决“嵌入是否可分/消息是否恶意”的统计检测问题；把 confidence 当密码学承诺是概念错误。

## 12. 可检验的研究假设（3–6 条）

以下均为**假设/推断**，需查证外部文献；本文未做，不等于无人做过。

- **H1（置信度感知的自适应攻击）**：若攻击者在生成时显式优化“低 token 熵/高置信度 + 高 Flip”，则 Table 4 的 Conf. AUROC 会显著下降，Ours 的攻击下准确率优势缩小。实验：在 near-benign prompt 中加入“必须非常自信、避免犹豫”的约束，或对候选消息按 C(m) 过滤，比较 Table 1 的 Acc-Avg。
- **H2（嵌入+置信度混合优于单信号）**：把 confidence 作为 G-Safeguard/GUARDIAN 的额外特征或门控（而非 standalone pruning），在 near-benign 攻击下应比任一单信号更稳。实验：2×2 设计（embedding on/off × confidence on/off），同一 MMLU/LLaMA 设置，报告 Acc-Avg/ASR。
- **H3（pruning vs down-weighting 的权衡）**：pruning 更硬、可能误删良性不确定消息；down-weighting 更柔、但依赖接收模型服从。假设存在一个 δ/权重区间，使 down-weighting 在保持 clean accuracy 的同时降低 ASR。实验：同一攻击集上比较两种策略的 accuracy–ASR Pareto 前沿。
- **H4（早期/拓扑感知干预）**：只在第 1–2 轮剪枝、或按入度/介数中心性调整阈值，能否在稠密拓扑下延缓信号崩塌并降低最终 ASR？实验：Table 5 的 8 种拓扑上做 early-stop pruning 与 topology-aware pruning。
- **H5（γ/L 的可测性）**：对 G-Safeguard/GUARDIAN 估计实际 Lipschitz 常数 L 与 benign margin γ，检验 γ/L 是否与 near-benign 攻击的成功半径 τ 同量级；若 γ/L 远小于 τ，Theorem 4.1 对实际攻击的解释力有限。实验：在固定嵌入模型上做 margin/Lipschitz 估计与攻击成功率扫描。
- **H6（跨模型迁移）**：在 LLaMA-3.1-8B 上优化的 near-benign 消息，迁移到 Qwen3-4B/GPT-4o-mini 时是否仍能降低嵌入可分性并拉低准确率？若迁移成功，说明攻击利用的是通用嵌入几何；若失败，说明攻击过拟合模型风格。实验：跨模型 zero-shot 攻击与 re-optimization 对比。
