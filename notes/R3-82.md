## 1. 150–300 字中文概述

ShadowMem 是面向 LLM Agent 长时程威胁的运行时防御框架。它借用系统安全中 shadow stack 的思想，维护一份独立于 Agent 工作记忆、仅防御方可见的自然语言“影子记忆”：每轮由记忆管理器 M 提炼用户意图、安全关切与已知攻击模式，判官 J 在工具调用执行前结合影子记忆判定该动作是否恶意，拒绝即阻断。M 与 J 共享一个 Qwen3-4B，用逐轮 GRPO 联合训练，奖励分别刻画判定正确性、记忆的时序信用、格式与长度。作者在两个威胁模型上评估：STAC 工具链攻击 ASR 从 100.0% 降到 8.3%、BU 94.4%、额外 7.0K token；PI2 持久注入 ASR 降到 0.0%、BU 73.0%。论文是经验型系统防御，不含形式化安全定义或密码学机制。

## 2. 研究背景、现有方法不足、精确定义的问题

- 背景：LLM Agent 被部署到多轮、长时程任务；攻击者可利用延长的 user–agent–environment 交互实施 multi-turn poisoning、tool-chaining、persistent prompt injection 等单轮场景中难以成立的攻击（p.1, §1）。
- 长时程攻击的定义性特征：恶意意图只在轨迹层面浮现，单轮内保持潜伏；而 keyword filter、逐轮分类器、safety prompting 等按短上下文设计，在长时程分布漂移下显著退化（p.1, §1）。
- 多轮防御的不足：MTSA 等把单轮防御扩展到多轮对齐训练，但交互长度超出训练区间后失效，且几乎只针对多轮 jailbreak，未覆盖更广的长时程威胁（pp.1–2, §1）。
- 间接提示注入防御的四类：prompt augmentation、model hardening、runtime detection、system-level（tool filtering / provenance / isolation）；作者称它们主要针对短上下文攻击，长交互下鲁棒性下降（p.2, §2.2）。
- 最接近的工作：TaskShield 做逐步骤任务对齐；DRIFT 用动态规则 + 注入隔离；AgentTrust 在工具调用前拦截但只匹配七条预定义攻击链；TRACES 用 observer LLM 的隐状态审计部分轨迹。作者认为这些方法依赖对齐检查/固定规则/预定义链，未学习“该保留什么”，而 ShadowMem 维护显式、自然语言、跨轨迹演化的安全记忆（p.3, §2.2）。
- 精确定义的问题：在 user-as-adversary 与 environment-as-adversary 两种设定下，给定三元交互轨迹，防御方要在恶意动作 a* 执行前尽可能早地检测对抗性指令 q* 或注入载荷 o*，同时尽量不干扰良性任务。形式化写法是一个判官 J 在每轮对候选动作给出决定与理由：d_t, e_t = J(a_t | τ_{t−1})，d_t ∈ {approve, reject}，目标是最大化检测准确率、最小化检测延迟（p.3, §3.2, Eq. 1）。

## 3. Agent 系统模型（组件、交互流程、信任边界）

- 组件：Agent 策略 π（前沿 LLM + 外部工具）；用户；环境；记忆管理器 M；判官 J；影子记忆 m。M 与 J 由同一个参数为 θ 的模型实例化，用角色提示区分（p.5, §4.2.3；p.4, Fig. 2(b)）。
- 交互形式化：q0 为初始指令；第 t 轮 Agent 依据历史选择工具调用 a_t；执行得到观察 o_t；用户可选给出后续指令 q_t；s_t = ⟨a_t, o_t, q_t⟩，s0 = ⟨∅, ∅, q0⟩；τ_{t−1} = s[0:t−1]；a_t ∼ π(a | τ_{t−1})，直到任务完成或达到horizon T（p.3, §3.1）。
- 影子记忆递推：m_t = M(m_{t−1}, s_{t−1})（Eq. 2）；判官在记忆条件下评估：d_t, e_t = J(a_t | m_t)（Eq. 3）（p.4, §4.1）。
- 工作流（Algorithm 1）：m0 ← ∅；每轮先由 Agent 提出 a_t；M 以 update_memory(content) 更新 m_t；J 以 assess_risk(decision, rationale) 评估；若 reject，报告 e_t 并 **return（整个任务终止）**；若 approve，执行 a_t、获得 o_t 与可选 q_t、追加轨迹；任务完成则返回（p.5, §4.2.2, Algorithm 1）。这个“拒绝即终止”是理解其 utility 口径的关键。
- 信任边界（按原文归纳）：(a) 用户与 Agent 之间：user-as-adversary 设定下用户即攻击者，可直接下指令（p.3, §3.2）；(b) 环境观察与 Agent 之间：environment-as-adversary 设定下攻击者控制工具返回内容（网页、邮件等）（p.3, §3.2）；(c) Agent 与影子记忆之间：影子记忆“never directly exposed to the agent”，但可被 Agent 行为间接影响，因此只提供“partial rather than deterministic information-flow isolation”（p.5, §4.2.1）；(d) 防御方/部署者与 M、J 之间：部署者运行 ShadowMem，M/J 是独立于 Agent 后端的外部小模型（p.3, §3.2；p.5, §4.2.3）。
- 边界的重要含义：M/J 与 Agent 不是进程级/OS 级隔离，而是提示词角色分离 + 独立模型；原文没有给出访问控制或完整性机制（见 §6、§10）。

## 4. 资产、攻击者目标/能力、威胁模型和前提假设

**资产**（按原文风险类别，p.3, §3.2）：
- 机密文件与商业情报（如 strategy.docx、财务预测、竞争分析、区域扩张计划）（p.7, Example 1.1；pp.17–18, §C.1）。
- 用户账户与通信渠道（邮箱、联系人、消息发送权限）（pp.17–19, §C.1/C.3）。
- 资金与支付操作（financial fraud）（p.3, §3.2）。
- 安全控制与审计痕迹（security control tampering、destructive cover-ups）（p.3, §3.2）。
- Agent 工具调用行为的完整性（是否执行了攻击者意图的动作）（p.1, §1）。

**攻击者目标**：通过一系列交互把 Agent 导向对抗状态 τ*，使其执行恶意动作 a* ∼ π(a | τ*)，例如删除关键文件；原文为清晰起见假设单一恶意动作，但称框架自然可扩展到多动作目标（p.3, §3.2）。恶意目标限定在工具调用接口可实现的范围：未授权数据外泄、金融欺诈、破坏性掩盖、安全控制篡改（p.3, §3.2）。

**攻击者能力**：
- user-as-adversary：直接向 Agent 注入一系列恶意指令 {q*}，逐步把 Agent 推向 τ*（p.3, §3.2）。
- environment-as-adversary：不能直接提示 Agent，但控制 Agent 的环境观察（检索网页、邮件等），把恶意载荷 {o*} 嵌入观察中（p.3, §3.2）。
- 默认 grey-box：攻击者观察 Agent 的执行轨迹 τ（在 prompt injection 设定下还包括良性用户指令），但不能访问 LLM 参数或已部署防御；可依据观察自适应改进策略（p.3, §3.2）。
- 自适应增强：知道 ShadowMem 架构、系统提示与判定标准，可构造 M-adaptive（污染影子记忆）、J-adaptive（特权提升提示绕过判官）、J/M-adaptive（两者结合）（p.8, §5.4.1；p.13, §6.4.1）。
- 更强设定：可在每次拒绝后读取判官反馈 e，甚至读取影子记忆 m，并据此重写载荷（e-aware / (m,e)-aware）（p.9, §5.4.2；p.13, §6.4.2）；附录 F.3.7 还给出可访问模型权重的白盒 GCG 设定（p.24, §F.3.7）。

**前提假设**：
- 防御方是 Agent 部署者，ShadowMem 以工具调用形式嵌入 Agent 循环，不修改 Agent 的核心推理管线（p.3, §3.2；p.2, §1）。
- 训练需要带逐动作标签的完整轨迹；标签由任务/攻击规格经 LLM-as-judge（GPT-5.4）生成并人工核验（p.5, §4.3.1；p.6, §5.1.2；p.10, §6.1.4）。
- 明确的 scope 排除：memory poisoning、goal drifting、非工具调用的 jailbreak 不在防御范围内（p.3, §3.2）。
- 单 Agent 设定；多 Agent 留作未来工作（p.14, §7）。

## 5. 核心方案（方法、攻击/防御流程、关键定义）

**5.1 设计动机与两个组件**
- 作者把长时程脆弱性归因于三点：有限工作记忆 vs 增长的上下文窗口导致对安全信息的注意力稀释；恶意意图只在轨迹层面出现而 Agent 缺乏回溯检查能力；安全对齐在短上下文训练、无法泛化到长交互（p.4, §4.1）。
- 影子记忆是一个紧凑的、以安全为中心的轨迹表示，与 Agent 的工作记忆并行；它只保留安全关键上下文、丢弃无关信息，从而抑制噪声并突出早期注入信号（p.4, §4.2.1）。
- 复杂度论证：直接用 J(a_t | τ_{t−1}) 评估全轨迹的累计开销为 O(T²)；用影子记忆 m_t 后为 O(T)，并降低推理延迟（p.4, §4.2.1）。

**5.2 关键公式与流程**
- Eq. (2)：m_t = M(m_{t−1}, s_{t−1})。
- Eq. (3)：d_t, e_t = J(a_t | m_t)。
- Algorithm 1：见 §3；M/J 作为原生 tool call 调用，避免特殊 token 与额外 SFT；每轮设 checkpoint，只有 J 批准才执行（p.5, §4.2.2）。
- 记忆内容为固定 schema：User's Intent、Security Concerns/Key Facts（who/what/target）、Pattern Match（与已知攻击类型匹配）；要求简洁、bullet、覆盖式写入（p.19–20, §D.1；p.7, Example 1.1；p.17, §C.1 的 m1–m3）。

**5.3 训练（turn-wise GRPO）**
- 数据：完整轨迹 τ = (s0,…,sT)，每个动作 a_t 带二值标签 d*_t（是否恶意）；标签按动作而非观察赋值——若 s_t 含注入但 a_t 本身良性，标签仍为负（p.5, §4.3.1）。
- 采用 GRPO 的逐轮变体：每轮采样 G 个记忆更新 m_{t,i} 与对应判官输出，记忆阶段与判官阶段分别计算重要性采样比与组归一化优势，避免跨阶段 reward hacking（pp.5–6, Eq. 4–7）。
- 判官奖励：R_judge = +1 若 d_t = d*_t，否则 −1（Eq. 8）。
- 记忆奖励：R_mem(m_t) = Σ_{k=t}^{T} γ^{k−t} · 1_{d_k = d*_k}，用指数衰减把未来判官结果回传给早期记忆更新（Eq. 9）。
- 格式惩罚：解析失败罚 0.1，并以安全兜底替代（判官 reject + 通用理由；记忆保留 m_{t−1}）（p.6）。
- 长度惩罚：|m_t| > 2500 字符时 R_length = −λ|m_t|/5000，否则 0；默认 λ = 1.0（Eq. 10；p.6）。
- 总奖励按阶段相加：判官 R_judge + R_format；记忆 R_mem + R_format + R_length（Eq. 11；p.6）。
- 实现：M 与 J 共享 Qwen3-4B-Instruct-2507；AdamW，lr 1e−6；4×H100；G = 8；ε_low = 0.2、ε_high = 0.28；β = 0.0；batch 32；Evaluation I 训练 2 epoch，Evaluation II 训练 10 epoch；Evaluation I γ = 0.25、λ = 1.0，Evaluation II γ = 0.0、λ = 1.0（p.21, §E.1）。
- 后端选择理由：目标 Agent 常用前沿大模型（如 GPT-5），而记忆提炼与风险评估是聚焦任务，小模型足够；独立模型可做任务特定训练并降低延迟/成本；共享一个模型还能让 M 直接为 J 优化（p.5, §4.2.3）。

**5.4 关键定义**
- 影子记忆（shadow memory）：与工作记忆并行、仅防御方访问的紧凑安全上下文表示；“inspired by, but not equivalent to” shadow stack（p.4, §4.2.1；p.5）。
- 检测延迟（detection latency/distance）：首个攻击轮与首个被检测到的恶意信号之间的轮级差；0 表示攻击轮当轮检测，负值表示提前预警，正值表示滞后（p.7, §5.3.2）。
- ASR：攻击实例中达成恶意目标的比例；BU：被防御 Agent 正确完成的良性任务比例；TC：防御每任务额外处理的 token 数（pp.6–7, §5.1.3）。

## 6. 安全声明与形式化程度（定义/指标/经验主张）

- **没有形式化安全定义、游戏、构造、定理或归约**。全文的形式化对象只有：Eq. (1) 的判官函数、Eq. (2)(3) 的记忆递推与条件判定、Eq. (4)–(7) 的 GRPO 目标、Eq. (8)–(11) 的奖励函数（pp.3–6）。这些是系统/优化方程，不是密码学或形式化安全模型。
- 作者自己明确否定“闭式不变量”式保证：shadow stack 可强制形如 return-address equality 的 closed-form invariant，而“malicious intent”是语义属性，“admits no such predicate”（pp.4–5, §4.2.1）。这是全文对“为何不能形式化”的最直接陈述。
- 隔离性只是部分的：影子记忆不直接暴露给 Agent，但可被 Agent 行为间接影响，原文称“partial rather than deterministic information-flow isolation”（p.5, §4.2.1）。这不是访问控制保证，也不是非干扰（noninterference）定理。
- 安全论证是经验性的：以 ASR 下降、BU 保持、检测提前、开销可接受四类指标支撑；没有任何最坏情况或计算复杂度意义上的对手优势界（pp.6–12）。
- 威胁模型是叙述式的：grey-box、两种设定、单动作目标、工具调用范围内的四类危害；没有对攻击者计算能力、查询次数、payload 长度的形式化约束（p.3, §3.2；pp.21–23, §F.1–F.2 只给 N_p、N_i 等实验预算）。
- 经验主张的措辞强于证据：摘要/引言称“first framework”“substantially outperforms existing defenses”（p.1）；但 Evaluation I 明确说没有针对 STAC 的现有防御，只能与自身消融变体比较（p.6, §5.1.2）；“consistently achieves the lowest ASR across all settings”（p.10, §6.2.1）在 Llama-3.3 的 Tool-Kg 上与 IPIGuard 的 0.0% 并列/略优关系并不严格（Table 5, p.11）。
- 指标层面：ASR/BU/TC 都是任务级或 token 级的操作指标；BU 以“任务是否完成”计，配合 Algorithm 1 的“拒绝即终止”，一个假阳性会直接抹掉整个任务（p.5, Algorithm 1；pp.6–7, §5.1.3）。
- **完整性/访问控制判定（专项核查）**：影子记忆的完整性完全依赖“语义记忆 + LLM 检查”，没有任何哈希链、签名、Merkle 树、MAC、加密或 attested channel。全文检索不到 integrity、hash、Merkle、signature（作为密码学原语）、encrypt、attestation 等机制；`signature` 只以“per-attack signatures / tool-specific signatures”的比喻出现（p.23, §F.3.1）。访问控制也只是提示词层面的角色分离（M 写、J 读、Agent 不直接读），没有强制机制。原文没有使用“tamper-proof”一词；“trusted”只出现在描述 Spotlighting 区分 trusted instructions 与 untrusted environment data（p.10, §6.1.3），不是对影子记忆的保证。

## 7. 实验设置与主要结果（agents、场景、指标、关键数字、消融）

**7.1 Evaluation I：user-as-adversary / STAC**
- 场景与数据：SHADE-Arena；247 个恶意（STAC）与 88 个良性任务，训练集 276 个（206 恶意 + 70 良性），与评测集严格不相交；平均攻击 horizon 3.43 轮，最大 24 轮；目标 Agent 后端 GPT-5.1；ShadowMem 后端 Qwen3-4B（p.6, §5.1.1–5.1.2）。
- 标签：LLM-as-judge（GPT-5.4）生成，人工核验准确率 98.1%（p.6, §5.1.2）。
- 主结果（Table 1, p.7）：No Defense ASR 100.0%、BU 100.0%；ShadowMem 8.3% ASR、94.4% BU、7.0K TC；J-only（Qwen3-4B，未训练）62.5% ASR、79.2% BU、12.9K TC；J-only（GPT-5-mini）37.5% ASR、50.0% BU；J-only + RL 16.7% ASR、77.8% BU；J+M 未训练 0.0% ASR / 0.0% BU（全拒）；J+M 只训练 J 12.5% ASR、88.9% BU、6.7K TC。
- Horizon 消融：No Defense 从 ≤2 轮的 89.7% 升到 ≥3 轮 >93%、≥5 轮 100%；ShadowMem 在所有 bucket 维持约 4.6%–10.0%，≥6 轮（含 24 轮）为 7.1%（p.7, §5.3.1；Fig. 3(a)）。
- 检测延迟：平均 −0.06 轮，多数在攻击轮当轮或相邻轮检出，非平凡比例提前预警（p.7, §5.3.2；Fig. 3(b)）。
- 记忆组件消融（Table 2, p.8）：去掉 user intent 参考 → ASR 12.5%、BU 83.3%；去掉 attack pattern 参考 → ASR 20.8%、BU 88.9%；完整 8.3%/94.4%。
- 超参敏感性（Fig. 4, p.8）：γ ∈ [0.25, 0.5] 最佳（8.3% ASR、94.4% BU）；γ = 0 → 12.5% ASR；γ = 0.99 → 16.7% ASR、83.3% BU；λ = 2 过度压缩 → 20.8% ASR、83.3% BU。
- 自适应攻击（Table 3, p.8）：未训练 J+M 在 M-/J-/J/M-adaptive 下 ASR 25.0%/12.5%/37.5%；RL 后 ShadowMem 为 8.3%/8.3%/12.5%。更强设定（Table 4, p.9）：算法优化循环 e-aware 12.5%、(m,e)-aware 12.5%；agentic harness（Codex + GPT-5.5）16.7%、25.0%。

- 训练数据规模（p.21, §E.2；Fig. 10）：Evaluation I 0 条轨迹 → 0% ASR/0% BU；138 条 → BU 66.67%、ASR 25.00%；276 条 → ASR 8.33%、BU 94.44%、TC 6,983。Evaluation II 0 → BU 5.41%、ASR 0%；2,000 → BU 51.35%、ASR 4.29%；4,000 → BU 54.05%、ASR 0.71%；6,000 → BU 59.46%、ASR 0.71%。

**7.3 评测口径的关键限制**
- Evaluation I 没有外部防御基线，只有 ShadowMem 自身消融（p.6, §5.1.2）；因此“outperforms existing defenses”主要由 Evaluation II 的 5 个基线支撑（p.10–11）。
- 两个评测的 no-defense BU 都接近上限（100.0 / 62.2–86.5），但不同 benchmark 不可横向比较。
- 所有 ASR 都是攻击实现下的经验值，未给出置信区间；15 seed 只覆盖推理方差，不覆盖训练方差（p.24, §F.3.6 明说）。

## 8. 贡献与创新点（按原文主张）

- 识别出防御长时程威胁的关键是“跨执行轨迹维护安全关键上下文”，并据此设计防御（p.2, 贡献列表第一条）。
- 提出 ShadowMem：作者称其为**首个**利用 agentic memory 蒸馏/保留安全上下文并做回溯式轨迹级风险评估的框架（p.2, 贡献第二条；p.3, §2.3 亦称“first to exploit agentic memory as a security primitive”）。
- 架构创新：memory manager + judge 双组件、共享一个小模型、以原生工具调用接入 Agent 循环、不修改 Agent 推理管线（plug-and-play）；输出自然语言理由，供操作员解释（p.2, §1；p.5, §4.2.2–4.2.3）。
- 训练创新：turn-wise GRPO，把记忆阶段与判官阶段的 token/奖励分离，避免跨阶段 reward hacking；记忆奖励用指数折扣把未来判官结果回传（pp.5–6, §4.3.2–4.3.3）。
- 经验贡献：跨两个威胁模型、两类长时程攻击（STAC、PI2）、多个 Agent 后端，报告 ASR/BU/TC/检测延迟，并给出自适应与白盒攻击评估（pp.6–14, §5–§7；pp.21–24, §E–§F）。
- 作者还贡献了开源 artifact（代码、数据、checkpoint、复现脚本）（p.16, §A）。

## 9. 局限、失败案例、作者承认的不足（区分作者承认 vs 你的推断）

**作者明确承认的（p.14, §7 Conclusion and Future Work）**
- 只评估了两个代表性长时程攻击；未覆盖 memory poisoning、goal drifting，也未覆盖 coding/computer-use 等 Agent 架构（p.14）。
- 评测 horizon 受现有 benchmark 限制（最多 24 轮），更长 horizon 未验证（p.14）。
- M/J 的 LLM 组件“not fully isolated”，可被能伪造合理解释的对手影响；加强隔离或用确定性保护替换部分组件仍是未来工作（p.14；并以 Example 1.4 的 (m,e)-aware 成功案例示范，p.9）。
- 影子记忆使用固定 schema（user intent + known attack patterns），未做动态 schema（p.14）。
- 只做单 Agent；多 Agent 未涉及（p.14）。

**作者在正文其它处承认的**
- STAC 没有现有防御可直接比较，Evaluation I 只能与自身变体比较（p.6, §5.1.2）。
- 未训练的 J+M 会盲目拒绝一切（0.0% ASR 伴随 0.0% BU），必须靠 RL 校准（p.7, §5.2.1）。
- memory poisoning、goal drifting、jailbreaking 明确不在威胁模型内（p.3, §3.2）。
- (m,e)-aware + agentic harness 可把 STAC ASR 推到 25.0%；作者称这是“residual attack surface”，且需要轨迹外不可验证的伪造上下文（p.9, §5.4.2）。
- 在 Evaluation II 的自适应设定下，攻击者若只能影响工具输出（而非用户查询），其载荷会被 m 中干净的用户意图对照，故 0.0%（p.13–14, §6.4.2）。

**我的推断（非作者承认）**
- Evaluation I 的评测集规模未直接给出；由 247−206=41 个恶意、88−70=18 个良性推算约 59 个任务 [推断]，样本量偏小，ASR 的分辨率约为 1/41 ≈ 2.4 个百分点 [推断]。
- 训练与评测同源（同一 benchmark、同一攻击生成器），F.3.1/F.3.2 的“泛化”仍在同一 benchmark family 内（Banking suite、PI2），不足以证明跨生态泛化 [推断，p.23]。
- 用 GPT-5.4 做 LLM-as-judge 生成训练标签、再用另一个 LLM 做防御，存在标签偏差与“用 LLM 监督 LLM”的循环性；人工核验 98.1%/98.7% 只说明抽样一致性，未报告标注者间一致性 [推断，p.6, p.10]。
- M/J 本身是 LLM，存在提示注入面；影子记忆是自然语言、无完整性绑定，一旦 M 被说服或出错，J 会消费被污染的记忆且没有回滚/审计机制 [推断，pp.4–5, pp.9–10]。
- Algorithm 1 的“reject 即 return”意味着任一假阳性都会终止整个任务；BU 只按任务完成计，无法区分“安全但低效”与“安全且高可用” [推断，p.5, pp.6–7]。
- TC 只计额外 token，未计本地 Qwen3-4B 的 GPU 成本；6.13 s/任务的额外延迟对交互式 Agent 可能不可忽略 [推断，p.24, §F.3.5]。
- 论文的“first”主张无法从文本内部验证；相关工作中已有 TaskShield/DRIFT/AgentTrust/TRACES 等“track-intent, check-each-step”方法，本文的差异化主要在“可学习的记忆保留”，而非“首个轨迹级检测” [推断，p.3, §2.2]。
- 检测延迟指标把“首个恶意信号”当检测点；这可能只是准备步骤（如文件搜索）被标记，而非最终恶意动作被阻止，指标偏乐观 [推断，p.7, §5.3.2]。

**原文内部不一致 / 数字矛盾（不得当作证据使用）**
- **λ 默认值冲突**：§6.3.5 称“default λ = 0.5”并说此时 3.6K token（p.13 顶部）；§E.1 明确写 Evaluation II “λ = 1.0”（p.21）；Table 6 的 ShadowMem 默认行是 TC 2.9K（p.12），Fig. 7 的 λ 曲线在 λ = 1 时约 3.3–3.4K（p.13）。三处口径不一致，本文不采用 3.6K/λ=0.5 作为默认配置证据。

## 12. 可检验的研究假设（3–6 条）

- **H1（记忆的必要性）**：在相同小模型（Qwen3-4B）与相同训练预算下，带影子记忆的 J+M 在轨迹级攻击上的 ASR 显著低于直接看原始轨迹的 J-only。检验：Table 1 的 62.5% → 8.3%（p.7）；可进一步做同数据、同 seed 的配对实验并报告置信区间。
- **H2（RL 校准的必要性）**：仅提示、不训练时，J+M 会退化为“全拒”（0% ASR、0% BU）；训练后才能在保持 BU 的同时降低 ASR。检验：Table 1 的 0.0/0.0 → 8.3/94.4（p.7）与 Table 6 的 5.4 BU → 59.5 BU（p.12）；可用拒绝率-覆盖率曲线验证。
- **H3（检测时点）**：对多数长时程攻击，首个正确拒绝发生在攻击轮当轮或之前（平均延迟 ≤ 0），且攻击 horizon 越长、提前量越明显。检验：Fig. 3(b)/Fig. 6(b) 的逐轮 detection distance 分布（p.7, p.12）；按 horizon 分层比较。
- **H4（鲁棒性上界由“轨迹外可伪造性”决定）**：当攻击者能读取 m/e 并向用户查询注入轨迹无法反驳的事实时，ASR 上升；只能影响工具输出时，ASR 接近 0。检验：Table 4 的 12.5% → 25.0%（p.9）与 Table 9 的 0.0%（p.14）的对照；可系统改变“可伪造事实”的数量。
- **H5（联合训练优于分离训练）**：联合训练 M 与 J 比只训练 J 更能同时提升 ASR 与 BU。检验：Table 1 的 J-only 12.5/88.9 → J+M 8.3/94.4（p.7）；Table 6 的 3.6/54.1 → 0.7/59.5（p.12）。
- **H6（跨环境迁移有限但存在）**：在一个 suite 上训练的 ShadowMem 能迁移到未见 suite/未见攻击，但性能低于同分布。检验：Banking 留出 9.7% ASR/100% BU（p.23）；PI2-only 训练 5.7% ASR/66.7% BU（p.23）；可扩展到第三个 benchmark 验证。
