## 3. 两种排行（必须分开看）

### 3.1 按 T_dir（密码学在方向上是否普遍）

2. A1、B2、B3、D1、E1、G1、G3：1
3. 其余 23 个二级：0（B4 的 T_dir=0，因 3 篇中 2 篇为 0）

### 3.2 按 T_ceiling（最好的一篇做到什么）

1. **B4 策略审计与可验证执行：4**（R3-80 zkAgent）
2. **B1 身份认证与委托：3**（R2-07、R1-03）
3. **T_ceiling=1**：A1、A3、B2、B3、C1、C4、D1、D2、D3、D4、E1、E2、E3、G1、G2、G3、G4、H1、H3（共 19 个叶；具体论文分见 `direction_scores_full.csv`）
4. 其余 10 个叶：0（A2、C2、C3、F1、F2、F3、H2、I1、I2、I3）

### 3.3 结论

- **B1 是唯一“广度 + 高度”都成立的方向**：两篇论文均为 T=3，分别覆盖委托架构（R2-07）与协议实现/符号验证（R1-03）。它不是“单篇 spike”。
- **B4 是“单篇 spike”**：R3-80 是语料中唯一的 T=4（形式定义 + SNARK 构造 + 定理/证明 + 原型），但同方向的 R3-02（ML 轨迹审计）与 R3-75（OS 运行时审计）均为 T=0。B4 的理论密码学高度集中在 R3-80，不能代表整个 B4 方向。
- **G3、A1、B2、B3、E1、G1 只有 T=1 的类比性**：它们能提出认证/完整性/授权/来源等可类比属性，但没有密码学定义、构造或证明。G3 的 R3-43 有隐写理论接口（T_potential=4），但已有贡献 T=1。
- **D、E、F、H、I 的多数方向 T=0**：benchmark、行为安全、语义防御、记忆投毒、Web/CUA 评测等没有理论密码学核心；不要因为出现 privacy/trust/verifiable 就抬分。

## 4. 三个校准案例（已有贡献，不是潜力）

### R3-80 zkAgent（T=4）
- **已做**：one-shot transcript 的 zk argument of knowledge / zkPC 形式定义（pp.39–40）；prefix-equivalence Lemma/Theorem 与证明（pp.52–53）；GKR + lookup + KZG/KZH 的 SNARK 构造；把 zkTLS/zkVM/Coral 工具观测绑定进单一 transcript proof；C++ 原型与端到端 weather/coding agent 证明。
- **未做**：没有完整组合 soundness 定理/归约；zkTLS 信任假设与 GPT-2 级性能限制未充分评估；不是新密码学原语/基础定义。
- **因此 T=4，不是 5**；A=4（有实现+实验+清晰 Agent 集成点，但部署成本未充分评估）。

### R1-03 SAGA（T=3）
- **已做**：X25519/OTK/DH/HKDF、ECDSA/Ed25519、X.509/TLS；Provider 注册表 + 联系策略 + 访问 token；ProVerif 符号验证；开源实现与性能测量；A2A 集成点。
- **未做**：无计算安全证明/新原语；Provider 强信任；token 是 bearer 且未绑定 task；缺端到端攻击实验。
- **因此 T=3、A=3**；T_potential=4（委托凭证不可伪造性/作用域不扩张/撤销/组合不变量）。

### R2-07 Authenticated Delegation（T=3）
- **已做**：OAuth 2.0/OIDC/W3C VC/数字签名；委托 token、scope、audience、撤销与审计的架构；user/agent/service/OP 信任边界。
- **未做**：无形式安全定义/证明；无原型/实验；更接近 Position/架构。
- **因此 T=3、A=3**；若严格按“仅调用现成 OAuth/签名”可下调到 2，报告在敏感性中给出 T=2 版本。

## 6. 负面证据与限制

1. **没有 T=5**：本语料没有新密码学原语/基础定义级工作；R3-80 是应用型新构造，不是新原语。
2. **B4 的 T_dir=0 不是笔误**：3 篇中 2 篇 T=0；方向上密码学不普遍，只有单篇 spike。
3. **B1 只有 2 篇**（low_n）：T=3 的稳定性有限；但两篇独立（Position + 协议实现）都指向同一问题，证据一致性较好。
4. **G3 的 T_potential=4 来自 R3-43，不是已有 T**：R3-43 没有密码学安全定义/归约；其“定理”是信息论/认识论论证。
5. **7 篇 FULLY_READ 不影响 T≥3 结论**：R3-80、R1-03、R2-07 均为 QUALITY_CHECKED，不是 FULLY_READ。
6. **分类置信度**：30 篇 medium 主类；若 B1/B4/G3 的论文被替代分类，方向 n 会变化，但 T≥3 的论文集合不变（R3-80/R1-03/R2-07）。

## 7. 理论密码学相关度排行（结论）

**按“最好现有工作”排序**：
1. B4（4，单篇 R3-80）
2. B1（3，R2-07 + R1-03）
3. A1/B2/B3/D1/E1/G1/G3（1，类比性）
4. 其余（0）

**按“方向内普遍性”排序**：
1. B1（3）
2. A1/B2/B3/D1/E1/G1/G3（1）
3. 其余（0，含 B4）

**一句话**：本语料中理论密码学相关度**高度集中**：只有 B1 同时具备“两篇 T=3”的广度，B4 具备“一篇 T=4”的高度；其余方向没有超过 T=1 的已有理论密码学贡献。B1 是唯一在两种口径下都稳定的方向；B4 是高上限、低广度的单点方向。
