## 3. 九个一级方向

### A. 研究总览、安全评测与审计（17）
- **研究对象**：跨攻击面的安全定义、SoK、通用 benchmark、测量方法、监控审计与漏洞发现。
- **关键安全问题**：Agent 安全的边界是什么；如何构造可复现、能区分能力与安全的评测；如何发现未知漏洞；如何审计系统行为。
- **代表性论文**：R1-01、R3-06、R3-48；R2-01、R2-02、R2-14、R2-19、R3-14、R3-15、R3-30、R3-45、R3-49、R3-52、R3-56；R2-13、R3-55、R3-69。
- **与相邻方向区别**：面向特定环境/协议/工具的 benchmark 回到 D/E/I 等对象分支；A 只保留跨攻击面的通用评测与审计方法。R3-57 是手机环境评测，因此归 I1 而非 A2；R3-65 是 MCP 专用 benchmark，因此归 E1。

### B. 身份、授权、权限治理与可信执行（13）
- **研究对象**：Agent 身份、委托授权、最小权限、capability、隔离、策略审计与可验证执行。
- **关键安全问题**：谁在代表谁行动；授权范围如何绑定、衰减与撤销；策略由谁执行；执行证据是否可信；密码学证明能否覆盖完整执行。
- **代表性论文**：R2-07、R1-03；R3-01、R1-02、R2-08、R3-79；R1-05、R1-06、R3-35、R3-72；R3-02、R3-75、R3-80。
- **与相邻方向区别**：B 关注授权与执行机制；D3 关注注入内容检测；H1 关注模型行为层的拒绝与护栏；C 关注数据机密性/信息流。B4a 是策略审计/运行时强制，B4b 是密码学可验证执行，二者不能混为一谈。

### C. 隐私、机密性与敏感信息流（17）
- **研究对象**：隐私规范、数据最小化、记忆隐私、跨服务外传、内部信息提取与再识别。
- **关键安全问题**：哪些数据可以进入上下文、记忆或外发；Agent 能否推断出未被直接提供的敏感信息；如何约束信息流；如何区分“语义隐私判断”与“可证明的隐私保证”。
- **代表性论文**：R1-04、R3-07、R3-08、R3-09、R3-42、R3-44、R3-63、R3-81；R2-11；R3-10、R2-23、R3-33；R3-03、R3-11、R3-28、R3-34、R3-59。
- **与相邻方向区别**：C2 是记忆中的个人隐私；F1/F2 是记忆/知识库完整性与污染；C4 是信息提取/推断，不是投毒；G2 是多 Agent 架构评测，C4 的 R3-59 是拓扑信息提取。

### D. 提示注入、任务劫持与行为偏移（24）
- **研究对象**：提示注入的机理、攻击入口、检测防御与多步控制流异常。
- **关键安全问题**：指令与数据能否分离；多源/多模态内容如何影响 Agent；跨动作的攻击链如何检测；工作流/控制流是否可被劫持。
- **代表性论文**：R1-09、R3-17；R1-13、R2-10、R2-15、R3-16、R3-27、R3-38、R3-39、R3-54、R3-70、R3-71、R3-84；R1-10、R1-14、R2-12、R2-16、R3-04、R3-19、R3-77；R3-18、R3-20、R3-36、R3-85。
- **与相邻方向区别**：D2 关注注入入口与攻击构造；D3 关注检测/训练/接口防御；D4 关注跨动作、控制流与轨迹级异常；E 关注工具/MCP/Skills 生态；H1 关注行为层拒绝/护栏。

### E. 工具、MCP 与 Skills 生态安全（11）
- **研究对象**：MCP 服务器/工具元数据、工具选择、跨工具数据流、Skills 供应链与后门。
- **关键安全问题**：工具描述是否可信；工具组合是否越权；Skills 发布/更新是否可验证；工具生态的供应链攻击。
- **代表性论文**：R1-07、R2-17、R3-13、R3-65；R1-11、R1-12、R3-47、R3-66、R3-86；R1-08、R3-23。
- **与相邻方向区别**：E1 是 MCP 协议/工具投毒；E2 是工具选择/元数据操纵/跨工具滥用；E3 是 Skills 供应链；C3 是经 MCP 的数据外传；F1 是记忆投毒。

### F. 记忆与知识库完整性（5）
- **研究对象**：记忆/知识库投毒、集体记忆与群体影响、记忆防护与语义监控。
- **关键安全问题**：攻击者能否写入/污染记忆；污染是否传播；防御能否区分恶意与良性写入；语义监控能否检测授权管线写入的恶意内容。
- **代表性论文**：R2-03、R3-83；R3-41；R3-22、R3-82。
- **与相邻方向区别**：C2 是记忆隐私；F1/F2 是完整性与污染；F3 是防护机制；G3 是多 Agent 消息级联；F3 的 R3-82 不是被攻击的 Agent 记忆，而是防御方私有语义记忆。

### G. 多智能体通信、协作与信任（14）
- **研究对象**：A2A 协议信任、多 Agent 架构/拓扑评测、级联/串谋/消息篡改、恶意 Agent 检测。
- **关键安全问题**：Agent 间消息是否可信；恶意 Agent 如何检测；串谋/隐写如何识别；拓扑是否泄露；架构如何影响安全。
- **代表性论文**：R2-18；R2-21、R3-12、R3-50、R3-58、R3-62；R2-22、R3-43、R3-68；R3-05、R3-24、R3-25、R3-26、R3-67。
- **与相邻方向区别**：C4 的 R3-59 是拓扑信息提取；G2 是架构/系统评测；G3 是消息/串谋攻击；G4 是检测防御；B1 是身份/委托机制。

### H. Agent 行为安全、对齐与模型脆弱性（13）
- **研究对象**：危险任务/拒绝/运行时护栏、后门/微调/训练数据风险、骨干模型/多模态/表示层鲁棒性。
- **关键安全问题**：模型是否会执行有害任务；拒绝是否可靠；后门是否可植入/检测；多模态与表示层是否稳健；护栏能否在运行时生效。
- **代表性论文**：R2-06、R2-24、R3-21、R3-29、R3-31、R3-37、R3-40、R3-53；R2-04、R2-05、R2-25；R2-20、R3-32。
- **与相邻方向区别**：H1 是行为/拒绝/护栏；H2 是训练数据/微调/后门；H3 是骨干/多模态/表示层；D3 是注入检测；B3 是系统隔离。

### I. 真实执行环境、资源与生态外部性（10）
- **研究对象**：Web/GUI/移动/CUA 环境风险、资源滥用/成本攻击、生态传播/内容保护/外部性。
- **关键安全问题**：真实环境中 Agent 能否造成伤害；资源/成本是否被滥用；Agent 生态的外部性如何约束；内容保护与反抓取如何平衡。
- **代表性论文**：R2-09、R3-46、R3-57、R3-60、R3-64、R3-73；R1-15、R3-61；R3-74、R3-76。
- **与相邻方向区别**：I1 是具体执行环境；I2 是资源/成本；I3 是生态传播与内容保护；D2 是注入攻击本身；A2 是通用 benchmark；C 是隐私/数据外传。

## 5. 交叉标签（受控词表）

标签可重复计数；与主类分离，不参与主类计数。

- **身份/授权**：`identity`(3)、`delegation`(4)、`capability`(2)、`least-privilege`(14)、`access-control`(12)、`consent`(9)
- **执行/证明**：`attestation`(1)、`provenance`(8)、`audit`(21)、`verifiable-execution`(2)、`isolation`(11)、`sandbox`(5)、`policy`(42)
- **安全属性**：`privacy`(23)、`pii`(21)、`confidentiality`(17)、`integrity`(31)、`availability`(5)、`accountability`(0)
- **攻击面**：`memory`(15)、`multi-agent`(23)、`mcp`(10)、`skills`(3)、`tool-selection`(17)、`web`(24)、`mobile`(5)、`gui`(12)、`cua`(13)、`prompt-injection`(67)、`jailbreak`(13)、`backdoor`(8)
- **贡献类型**：`benchmark`(59)、`sok-position`(3)、`human-in-the-loop`(9)

> 计数为本语料内出现次数，不代表全领域热度；一篇论文可带多个标签。`accountability` 当前为 0，保留为后续扩展词。

## 6. 分类规则

1. **单一主类**：每篇一个 `primary_category`，用于计数；多个 `secondary_categories` 与 `cross_tags`。
2. **按研究对象而非产出形态归类**：特定环境/协议/工具的 benchmark 归对象分支；只有跨攻击面的通用 benchmark 归 A2。
3. **主类优先级**：同时提出攻击与防御时，按核心研究问题归类；核心现象/威胁属于哪个对象，就归哪个主类。
4. **边界注释**：跨类论文必须在 `boundary_note` 说明为何选此主类、哪些内容放交叉标签。
5. **不改变编号**：R1/R2/R3 编号不变；迁移只改 mapping。
6. **证据可追溯**：每次迁移在 `taxonomy_change_log.md` 给出论文 ID、旧/新类、笔记证据位置与理由。
7. **密码学维度独立**：分类不评价密码学相关度；T_crypto/A_crypto 在阶段三独立评分，避免把“有签名/有证明”当作分类依据。

## 7. 置信度与限制

- 逐篇分类置信度：**high 94 篇、medium 30 篇、low 0 篇**（`registry/paper_topics_v1_1.json`）。
- 主要 medium 来源：A2/B4a 边界（R2-08、R3-15、R3-30、R3-55）、C1/I1 边界（R3-63）、H1/H3 边界（R3-53、R3-40）、G4 防御强度（R3-67）。
- 7 篇 `FULLY_READ`（R2-25、R3-62、R3-63、R3-64、R3-66、R3-71、R3-84）仍可分类，但其附录/补充材料未核对，分类置信度可能受影响。
- 124 篇是定向调研样本，不是全领域全集；本分类是**本语料的实用分类**，不是学术标准。
- A2/B4 的边界规则是本项目的工作约定，不是唯一正确分类；后续若出现新证据，可在 v1.2 调整。
