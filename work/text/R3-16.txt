A. Statements

A.1. Reproducibility Statement
We release the full TRAP framework and accompanying code at https://oxrml.com/its-a-trap/, where the
most up-to-date version is maintained. The repository contains: (i) complete experiment scripts and configuration files
reproducing every result reported in the paper; (ii) a README.md with end-to-end setup and run instructions; (iii) the exact
model identifiers, temperature, step limits, and other runtime parameters used for each table and figure; and (iv) the modular
injection templates, so that researchers can extend the benchmark with new persuasion principles, manipulation methods, or
interaction vectors. Model access is routed through OpenRouter using a user-supplied API key. We pin model versions by
date and provider identifier, but cannot guarantee bit-level reproducibility for externally hosted models whose behaviour
may shift after release.

C.4. Single-click attack success metric

We measure whether the agent clicks a link or button redirecting to an attacker-controlled website. This captures a critical
security boundary: once an agent navigates to attacker-controlled content, arbitrary follow-up attacks become possible
(credential harvesting, further injections, data exfiltration). Figure 15 illustrates how a single redirect can enable a multi-stage
attack that ultimately results in harm.

We adopt single-click rather than downstream harm for two reasons. First, it isolates the agent’s susceptibility to the
initial injection from its behaviour on the attacker’s page, these are distinct failure modes. Second, it yields an objective,
reproducible metric independent of attacker creativity in designing follow-up payloads.
