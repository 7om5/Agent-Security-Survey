A. Proof of Theorem 4.1

We first state a standard Lipschitz lower-bound lemma that converts a margin on a set into a guaranteed neighborhood.
Lemma A.1 (Lipschitz lower bound via distance to a set). Let s : Rd → R be L-Lipschitz w.r.t. ∥ · ∥2, i.e.,

                                               |s(u) − s(v)| ≤ L∥u − v∥2, ∀u, v ∈ Rd.
Let S ⊆ Rd be any nonempty set and define dist(h, S) := infz∈S ∥h − z∥2. Then for every h ∈ Rd,

                                                    s(h) ≥ inf s(z) − L dist(h, S).

                                                                                           z∈S

Proof. Fix any h ∈ Rd and any ε > 0. By definition of inf, there exists zε ∈ S such that
                                                        ∥h − zε∥2 ≤ dist(h, S) + ε.

By L-Lipschitzness,

                     s(h) ≥ s(zε) − L∥h − zε∥2 ≥ s(zε) − L dist(h, S) + ε .

Since s(zε) ≥ infz∈S s(z), we obtain

                                                s(h) ≥ inf s(z) − L dist(h, S) − Lε.

                                                                                    z∈S

Because ε > 0 is arbitrary, letting ε → 0 yields

                                       s(h) ≥ inf s(z) − L dist(h, S).

                                                      z∈S

Proof of Theorem 4.1. Recall the acceptance region Ω := {h : s(h) ≥ 0} and the benign support SB. By assumption, the
scoring function has benign margin γ > 0 on SB:

                                               inf s(h) ≥ γ.

                                              h∈SB

Apply Lemma A.1 with S = SB. For any h ∈ Rd,

                     s(h) ≥ inf s(z) − L dist(h, SB) ≥ γ − L dist(h, SB).

                                    z∈SB

Therefore, if dist(h, SB) ≤ γ/L, then

                                       s(h) ≥ γ − L · (γ/L) = 0,

which implies h ∈ Ω. Equivalently,

                                       {h : dist(h, SB) ≤ γ/L} ⊆ Ω.

Finally, for any attack embedding ha with dist(ha, SB) ≤ γ/L, the same inequality gives s(ha) ≥ 0, so it is guaranteed to
be accepted (i.e., it evades any defense that thresholds s(·) at 0).
