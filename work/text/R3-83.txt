Figure 2: Attack Scenario of MemPoison. The attack consists of two stages: injection (left) and triggering (right). (1) During
injection, the attacker can poison the agent memory through two pathways: (A) conversational injection via shared memory,
where malicious content is introduced through normal interactions in shared agent environments; and (B) indirect injection via
external resources, where compromised contents are processed by the victim agent and subsequently incorporated into memory.
Before storage, the agent applies a memory preprocessing pipeline, which may filter or rewrite the input. (2) During triggering,
the poisoned memory can be activated through two pathways: (A) indirect activation, where hidden triggers embedded in
external resources are naturally incorporated into user-agent interactions; and (B) direct activation, where trigger-containing
queries retrieve the poisoned memory. In both cases, the agent produces a harmful response derived from the poisoned memory.
